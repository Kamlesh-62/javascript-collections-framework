The package no longer ships source maps, so it installs at about 2.1 MB instead of 5.2 MB; the ES module and CommonJS builds remain readable as published. The README opens with a quick start and a comparison with native collections and other libraries, and shows the npm version, bundle size and dependency count. A new page, "Coming from native JavaScript", puts each native pattern next to its collection, and a playground runs the package in the browser without installing it.
