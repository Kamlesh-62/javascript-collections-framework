Add unmodifiable views and `asList`. `unmodifiableCollection`, `unmodifiableSequencedCollection`, `unmodifiableList`, `unmodifiableSet`, `unmodifiableSequencedSet`, `unmodifiableSortedSet`, `unmodifiableMap`, `unmodifiableSequencedMap` and `unmodifiableSortedMap` return read-only windows onto a collection: reads show the owner's changes, iteration fails fast or runs live as the source does, map entries read the source live, and every method that would change the view, its derived views, cursors or entries throws `UnsupportedOperationError` before looking at its arguments. List, set and map views equal their source; collection views compare by identity. Read-only wrappers never nest: given a view of the same kind, a view function returns it itself (`unmodifiableList(view) === view`), and given any other unmodifiable view or an immutable collection, it wraps what that collection reads, under its own name and family, with entries from an entry view still read-only. `asList(array)` returns a list over the array itself: every change through the list writes to the array, a direct change of the array's length makes open iterators fail fast, and frozen, sealed and non-extensible arrays are refused before any write.
