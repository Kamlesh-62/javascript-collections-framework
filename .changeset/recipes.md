The README links runnable recipes for common tasks: the k largest values of a stream, merging sorted arrays, the maximum of each sliding window, an LRU cache, a booking calendar that rejects overlaps, the shortest path on a grid, a running median, the most recent distinct items, and the events inside a time range. Each recipe states its collection and time complexity, prints its results with the exact output in a comment, and opens in StackBlitz. No change to the package's code.
