Add `HashMap`, the `MapCollection`, `ReadonlyMapCollection` and `MapEntry` types, the `HashMapOptions` type and the `isMapCollection` guard. A default `HashMap` behaves like native `Map` — `set` returns the map, `get`/`has`/`delete`/`clear`/`size`/`keys`/`values`/`entries`/`forEach((value, key, map))`, insertion order, SameValueZero keys (`-0` stored as `0`), `null` and `undefined` as keys and values, live iteration, and `getOrInsert`/`getOrInsertComputed` with the native semantics on every runtime — and `new Map(hashMap)` copies it. A `key` or `equivalence` option compares keys by value; derived keys and hashes are computed once and stored. It adds `getOrDefault`, `containsValue`, `put`, `putAll`, `remove`, `replace`, `replaceAll`, `compute`, `computeIfPresent` and `merge` (a result of `undefined` removes the mapping), live `keySet()`, `entrySet()` and `valueCollection()` views, entries that write through with `setValue`, `equals` comparing mappings in any order, `toJSON()` returning `[key, value]` pairs, and `HashMap(1) {'a' => 1}` printing. Construction input must be `[key, value]` arrays of length 2 or map entries. Maps are not collections: `isCollection` is `false` for them.
